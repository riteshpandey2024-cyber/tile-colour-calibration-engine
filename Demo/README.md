# Demo Video

This folder contains a demonstration video of the Tile Colour Calibration Engine in action.

## Contents

- **Demo.MOV** - A video demonstration showing the complete workflow of the tile colour calibration system

## What the Demo Shows

The demo video demonstrates:

- How to upload master and production tile images
- The colour analysis process and Delta E calculations
- Real-time visual comparison between master and production tiles
- AI-powered recommendations for colour correction
- The calibration interface and user workflow

## How to Use

Simply play the `Demo.MOV` file to see the full demonstration of the tile colour calibration engine's features and capabilities.

## System Requirements

The demo video can be played with:
- QuickTime Player (macOS)
- VLC Media Player
- Any standard video player supporting MOV format
